# Maxx Deli & Shop

The Maxx Deli & Shop website, built with Eleventy, Nunjucks, Tailwind CSS, and Alpine.js.

## Development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

Set `SITE_URL` to the public site origin when creating a deployment build.

The location, phone number, hours, and menu are placeholders until final business details are available.
